# Visualizações Interativas com D3.js

## Sobre o Projeto

Este repositório contém a implementação de uma visualização de dados interativa desenvolvida com **D3.js**, como parte da **Atividade Ponderada 2 de UX**.

O objetivo do projeto é explorar conceitos de visualização de dados, interatividade e manipulação dinâmica de elementos gráficos no navegador.

---

## Objetivo

Criar uma visualização interativa que:

* Represente dados de forma clara e compreensível
* Permita interação do usuário
* Utilize recursos nativos do D3.js para manipulação e animação

---

## Requisitos da Atividade

A aplicação desenvolvida deve:

* Estar conectada a um conjunto de dados
* Gerar a visualização completa em uma página HTML
* Exibir uma legenda explicativa
* Incluir pelo menos uma animação (`transition()`)
* Possuir interação com o usuário (ex: `drag`, `brush`, `quadtree`)
* Implementar zoom ou pan (`d3.zoom()`)
